# Документация проекта Geometric Library

## 1. Общее описание решения
Данный проект представляет собой программную библиотеку на языке Python, предназначенную для расчета площадей и периметров базовых геометрических фигур (прямоугольник, треугольник). Проект разработан в рамках лабораторных работ по дисциплине документирования ИТ-продуктов.

## 2. Описание функций с примерами вызова

### Модуль `rectangle.py`
- **Функция `area(x, y)`**
  * *Описание:* Вычисляет площадь прямоугольника.
  * *Параметры:* `x` (длина), `y` (ширина).
  * *Пример вызова:* `area(5, 10)` вернет `50`.
- **Функция `perimeter(x, y)`**
  * *Описание:* Вычисляет периметр прямоугольника.
  * *Параметры:* `x` (длина), `y` (ширина).
  * *Пример вызова:* `perimeter(5, 10)` вернет `30`.

### Модуль `triangle.py`
- **Функция `area(a, h)`**
  * *Описание:* Вычисляет площадь треугольника по стороне и высоте.
  * *Параметры:* `a` (сторона), `h` (высота).
  * *Пример вызова:* `area(10, 5)` вернет `25.0`.
- **Функция `perimeter(a, b, c)`**
  * *Описание:* Вычисляет периметр треугольника по трем сторонам.
  * *Параметры:* `a`, `b`, `c` (стороны треугольника).
  * *Пример вызова:* `perimeter(3, 4, 5)` вернет `12`.

## 3. План тестирования

### 3.1. Цели и задачи тестирования
* **Цель тестирования:** подтвердить корректность математических вычислений площадей и периметров геометрических фигур, реализованных в библиотеке, а также автоматизировать проверку функциональности при последующих изменениях кода.
* **Задачи тестирования:**
  * составить набор ручных и автоматизированных тест-кейсов для всех публичных функций библиотеки;
  * проверить работу функций на стандартных, граничных (нулевых), дробных и некорректных (отрицательных) входных данных;
  * реализовать модульные (unit) тесты с использованием стандартной библиотеки `unittest` в файлах `test_rectangle.py` и `test_triangle.py`;
  * зафиксировать результаты прохождения тестов и выявленные особенности поведения программы.

### 3.2. Описание тестируемого продукта
Тестируемый продукт представляет собой библиотеку на языке Python, состоящую из двух независимых модулей (`rectangle.py` и `triangle.py`), не использующих внешние зависимости. Каждая функция принимает числовые аргументы (`int` или `float`) и возвращает вычисленное значение площади или периметра. Валидация входных данных (проверка на отрицательные значения и неравенство треугольника) в текущей версии библиотеки не предусмотрена — функции выполняют прямые алгебраические вычисления.

### 3.3. Область тестирования
В область тестирования входят следующие модули и функции:
* **Модуль `rectangle.py`:**
  * `area(x, y)` — расчет площади прямоугольника по формуле $S = x \cdot y$;
  * `perimeter(x, y)` — расчет периметра прямоугольника по формуле $P = 2 \cdot (x + y)$.
* **Модуль `triangle.py`:**
  * `area(a, h)` — расчет площади треугольника по формуле $S = 0.5 \cdot a \cdot h$;
  * `perimeter(a, b, c)` — расчет периметра треугольника по формуле $P = a + b + c$.

*Вне области тестирования:* нагрузочное тестирование, тестирование безопасности, тестирование пользовательского интерфейса (GUI/CLI в проекте отсутствует).

### 3.4. Стратегия тестирования
Для проверки качества продукта применяются следующие виды и техники тестирования:
* **Виды и уровни тестирования:**
  * ручное функциональное тестирование (по предварительно составленным тест-кейсам);
  * автоматизированное модульное (unit) тестирование с использованием фреймворка `unittest` (запуск командой `py -m unittest discover -v`).
* **Техники тест-дизайна:**
  * *эквивалентное разбиение:* проверка на представителях классов положительных целых чисел и чисел с плавающей точкой (`float`);
  * *анализ граничных значений:* проверка поведения при нулевых значениях сторон/высоты (`0`), равных сторонах (квадрат, равносторонний треугольник), а также при выходе за область допустимых геометрических значений (отрицательные числа, невыполнение неравенства треугольника).

### 3.6. Критерии приемки
Тестирование считается успешно завершенным, а продукт — готовым к приемке при выполнении следующих условий:
1. Покрытие всех публичных функций модулей `rectangle.py` и `triangle.py` модульными тестами (`100%` функций покрыто тестами).
2. Успешное прохождение всех `19` автоматизированных unit-тестов (`Ran 19 tests ... OK`, `0` ошибок и падений).
3. Отсутствие математических ошибок в формулах вычисления площади и периметра на корректных входных данных.
4. Размещение исходного кода тестов в общедоступном репозитории GitHub и актуализация технической документации.
