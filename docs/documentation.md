# Документация проекта Geometric Library

## 1. Общее описание решения
Данный проект представляет собой программную библиотеку на языке Python, предназначенную для расчета площадей и периметров базовых геометрических фигур (прямоугольник, треугольник). Проект разработан в рамках лабораторных работ по дисциплине документирования ИТ-продуктов.

## 2. Описание функций с примерами вызова

### Модуль `rectangle.py`
* **Функция `area(a, b)`**
  * *Описание:* Вычисляет площадь прямоугольника.
  * *Параметры:* `a` (сторона), `b` (сторона).
  * *Пример вызова:* `area(5, 10)` вернет `50`.
* **Функция `perimeter(a, b)`**
  * *Описание:* Вычисляет периметр прямоугольника.
  * *Пример вызова:* `perimeter(5, 10)` вернет `30`.

### Модуль `triangle.py`
* **Функция `area(a, h)`**
  * *Описание:* Вычисляет площадь треугольника по стороне и высоте.
  * *Пример вызова:* `area(10, 5)` вернет `25.0`.
* **Функция `perimeter(a, b, c)`**
  * *Описание:* Вычисляет периметр треугольника по трем сторонам.
  * *Пример вызова:* `perimeter(3, 4, 5)` вернет `12`.
